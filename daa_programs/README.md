# 7 DAA Exam-Ready Python Programs
Shortest practical Python implementations with dynamic inputs, aligned sample inputs, and expected outputs.

Based on Model Exam Preparation for Design and Analysis of Algorithms (DAA).

## Programs Included:
1. `01_huffman_coding.py` - Greedy Algorithm (Min Heap)
2. `02_matrix_chain_multiplication.py` - Dynamic Programming
3. `03_longest_common_subsequence.py` - Dynamic Programming (LCS)
4. `04_knapsack_memoization.py` - 0/1 Knapsack with Memory Functions
5. `05_n_queens.py` - Backtracking
6. `06_graph_coloring.py` - Backtracking (m-Colorability)
7. `07_traveling_salesperson.py` - Branch and Bound (TSP)

## How to Run:
Each script accepts standard dynamic runtime input (`sys.stdin` / `input()`).
For example:
```bash
python3 01_huffman_coding.py < sample_inputs/01_input.txt
```
